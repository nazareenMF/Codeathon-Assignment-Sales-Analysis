# Codeathon-Assignment-Sales-Analysis
Business Analytics Dashboard -- Order & Profit Analysis

 Project Overview

This project is an interactive Power BI Business Analytics Dashboard
developed using a cleaned sales/order dataset.The main objective is to analyze order patterns, product demand, sales
performance, and profit trends over time, and to convert the analysis into meaningful business insights and recommendations.
The dashboard is designed as a multi-page interactive report withKPIs, charts, slicers, bookmarks, page navigation, and drill-through
analysis.

Project Objectives

The project focuses on:

Analyzing order distribution across regions

Identifying the top 5 trending products based on order frequency

Understanding profit trends over time

Comparing product and category performance

Monitoring sales and profitability

Providing business-oriented insights and recommendations

Creating an interactive and user-friendly Power BI report

 Drill-Through Analysis

A dedicated Product Details drill-through page is included.

Users can right-click a product from the product analysis visual and
select:

Drill through → Product Details

The drill-through page provides product-specific information such as:

Sales Trend

A Back button allows the user to return to the original analysis
page.

The drill-through page is kept separate from the normal page navigation
to maintain a clean dashboard experience.

 Business Recommendations

Based on the analysis, the dashboard supports recommendations such as:

Inventory Management

Monitor frequently ordered products and maintain suitable inventory
levels according to observed demand.

Regional Strategy

Compare order contribution and profitability across regions and
investigate significant regional differences.

Profitability Improvement

Investigate periods of declining profit and review factors such as
pricing, discounts, product mix and costs.

Product Strategy

Pay attention to products with high demand but relatively low profit and
evaluate their pricing and cost structure.

Performance Monitoring

Use the interactive dashboard regularly to identify changes in product,
regional and time-based performance.
